# ТРИВОГА UA — PWA

## Що використовує застосунок
- Власний інтерфейс та інтерактивна карта на Leaflet.
- Межі територій: `https://neptun.in.ua/oblasts.geojson`.
- Статуси тривог: `https://neptun.in.ua/api/v1/alerts`.
- Оновлення статусів кожні 10 секунд (REST-джерело рекомендує не частіше 5 секунд).
- Червоний — тривога на всю область; жовтий — тривога в одному чи кількох районах; зелений — активної тривоги не отримано.

NEPTUN надає безкоштовний API без ключа, але вимагає видиме посилання на джерело. API має відкритий CORS. Дані агрегатора можуть затримуватися або бути неточними.

## Запуск
1. Розпакуйте архів.
2. Завантажте всі файли на HTTPS-хостинг (GitHub Pages, Netlify або Cloudflare Pages).
3. Відкрийте адресу на Android у Chrome.
4. Меню браузера → «Установить приложение» / «Добавить на главный экран».

Локальний тест: `python -m http.server 8000`, потім `http://localhost:8000`.

## Безпека
Це інформаційний застосунок, а не офіційна система оповіщення. Не покладайтеся на нього як на єдине джерело безпеки. У разі сигналу тривоги прямуйте в укриття та дотримуйтеся вказівок місцевої влади.

## Ліцензії та атрибуція
Зберігайте видиме посилання на NEPTUN поруч із картою/даними відповідно до умов його API. Підкладка OpenStreetMap має атрибуцію внизу карти.
